🎯 COMO USAR (PASSO A PASSO)
═══════════════════════════════════════════════════════════════════════════

PASSO 1: Ativar Ambiente Virtual
─────────────────────────────────
$ cd /media/jean/7AF8AFA7F8AF5FDD/gestao_clinica
$ source .venv/bin/activate


PASSO 2: Instalar Dependências (primeira vez)
──────────────────────────────────────────────
$ pip install -r requirements.txt


PASSO 3: Configurar Google Cloud
────────────────────────────────
1. Ir a: https://console.cloud.google.com
2. Criar/Selecionar projeto
3. Habilitar Google Docs API
4. Criar Service Account
5. Gerar chave JSON
6. Copiar arquivo para: ./credentials.json


PASSO 4: Configurar .env
──────────────────────────────
GOOGLE_DOCS_TEMPLATE_ID=ID_DO_SEU_TEMPLATE_AQUI
GOOGLE_SERVICE_ACCOUNT_FILE=./credentials.json


PASSO 5: Rodar Localmente
──────────────────────────
$ bash run_local.sh

   OU (específico):

$ bash run_local.sh streamlit       # Streamlit (recomendado)
$ bash run_local.sh flask          # Flask
$ bash run_local.sh test           # Testar conexão


PASSO 6: Acessar no Navegador
──────────────────────────────
Streamlit:  http://localhost:8501
Flask:      http://localhost:5000
